HALOCAKE - INSTALASI LARAGON

1. Extract ZIP sehingga file berada di C:\laragon\www\halocake\index.html
   (Folder kerja Laragon bisa berbeda jika instalasinya dipindah.)
2. Buka Laragon -> Start All (Apache + MySQL/MariaDB).
3. Laragon -> Database (HeidiSQL) -> File -> Load SQL file ->
   pilih C:\laragon\www\halocake\database\schema.sql -> Run (F9).
4. Cek config\app.php. Sesuaikan db_port/db_user/db_pass jika diperlukan.
5. Buka http://localhost/halocake/api/health.php
   Harus muncul ok:true dan crossing_configured:true.
6. Buka http://localhost/halocake/
   Atau http://halocake.test/ jika Auto Virtual Hosts aktif (klik Reload).
7. Untuk uji tanpa ESP32, dari PowerShell dalam folder halocake:
   powershell -ExecutionPolicy Bypass -File .\examples\test-ingest.ps1
8. Untuk MQTT, import nodered\flow-halocake.json ke Node-RED,
   samakan API_KEY dengan config\app.php, lalu Deploy.

PENTING: Jangan dibuka langsung sebagai file:// .
Lihat README.md untuk detail lengkap dan batasan keamanan.
